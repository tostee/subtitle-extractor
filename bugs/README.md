# Registro de bugs

Cada bug reportado tiene su propia carpeta `Bug N` (numeración correlativa: Bug 1, Bug 2, …).

Dentro de cada carpeta hay un `README.md` con esta estructura:

```markdown
# Bug N — <título corto>

- **Fecha:** AAAA-MM-DD
- **Estado:** Abierto | Corregido | No reproducible
- **Versión afectada:** x.y.z
- **Commit(s) de la corrección:** <hash>

## De qué trata
<síntoma reportado y pasos para reproducirlo>

## Impacto
<a quién afecta, gravedad, qué deja de funcionar>

## Resumen de lo que se hizo
<causa raíz, corrección aplicada, archivos tocados, cómo se verificó / test añadido>
```
