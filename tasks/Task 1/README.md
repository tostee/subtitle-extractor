# Task 1 — Crear el registro de tareas y bugs

- **Fecha:** 2026-11-10
- **Estado:** Completada

## De qué trata
Crear una estructura de carpetas para dejar constancia de cada pedido y de cada bug reportado:
una carpeta `Task N` por pedido dentro de `tasks/`, y lo mismo para los bugs (`Bug N` dentro de `bugs/`).
En cada carpeta debe quedar un `.md` con de qué trata, el impacto y el resumen de lo que se hizo.

## Impacto
- Solo documentación: no cambia el código ni el comportamiento de la app.
- A partir de ahora cada pedido y cada bug queda registrado con su carpeta propia, lo que da trazabilidad del trabajo.

## Resumen de lo que se hizo
- Creadas las carpetas `tasks/` y `bugs/` en la raíz del repo.
- `tasks/README.md` y `bugs/README.md`: explican la convención, incluyen la plantilla del `.md` y un índice.
- `tasks/Task 1/README.md`: este registro.
- `CLAUDE.md` del proyecto: regla para que Claude cree y mantenga estos registros en cada sesión futura.
