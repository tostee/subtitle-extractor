# Registro de tareas

Cada pedido tiene su propia carpeta `Task N` (numeración correlativa: Task 1, Task 2, …).
Los bugs reportados se registran igual en [`../bugs`](../bugs) como `Bug N`.

Dentro de cada carpeta hay un `README.md` con esta estructura:

```markdown
# Task N — <título corto>

- **Fecha:** AAAA-MM-DD
- **Estado:** En curso | Completada | Descartada
- **Commit(s):** <hash> (si aplica)

## De qué trata
<el pedido, con las palabras del usuario cuando sea posible>

## Impacto
<qué cambia para el usuario / qué partes de la app o del repo se ven afectadas>

## Resumen de lo que se hizo
<cambios realizados, archivos tocados, decisiones tomadas, cómo se verificó>
```
