# Instrucciones del proyecto

## Registro de tareas y bugs (obligatorio)
- Cada pedido del usuario → nueva carpeta `tasks/Task N/` (N correlativo, siguiente al mayor existente) con un `README.md`.
- Cada bug reportado por el usuario → nueva carpeta `bugs/Bug N/` con un `README.md`.
- El `README.md` sigue la plantilla de `tasks/README.md` o `bugs/README.md`: **De qué trata**, **Impacto**, **Resumen de lo que se hizo** (más fecha, estado y commits).
- Crear la carpeta al empezar el trabajo (estado "En curso"/"Abierto") y completarla al terminar; añadir la fila al índice del `README.md` correspondiente.
- Escribir en español.
